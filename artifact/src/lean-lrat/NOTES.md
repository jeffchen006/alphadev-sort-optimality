# lean-lrat notes: Lean 4 v4.33.1 SAT/LRAT API and trust base

## 1. What Lean core v4.33.1 ships (read from `~/.elan/toolchains/leanprover--lean4---v4.33.1/src/lean`)

| item | file | what it is |
|---|---|---|
| `Std.Sat.CNF α` | `Std/Sat/CNF/Basic.lean` | `structure CNF α where clauses : Array (List (α × Bool))`; literal `(v, true)` = positive |
| `CNF.eval a f`, `CNF.Unsat f` | same | `Unsat f := ∀ a, eval a f = false` |
| `CNF.relabel r f`, `CNF.eval_relabel` | `Std/Sat/CNF/Relabel.lean` | `eval a (relabel r f) = eval (a ∘ r) f` |
| `CNF.dimacs : CNF Nat → String` | `Std/Sat/CNF/Dimacs.lean` | DIMACS text; **adds 1 to every variable** (var 0 → `1`) |
| `LRAT.IntAction` | `Std/Tactic/BVDecide/LRAT/Actions.lean` | `Action (Array Int) Nat`: `addEmpty / addRup / addRat / del` |
| `LRAT.parseLRATProof : ByteArray → Except String (Array IntAction)` | `Std/Tactic/BVDecide/LRAT/Parser.lean` | text or binary LRAT (binary if first byte is `a`/`d`); NOT verified (not needed) |
| `LRAT.check : Array IntAction → CNF Nat → Bool` | `Std/Tactic/BVDecide/LRAT/Checker.lean` | verified checker (compact LRAT checker, Josh Clune / Henrik Böving) |
| `LRAT.check_sound : check p cnf → cnf.Unsat` | same | the soundness theorem |
| `Reflect.verifyCert (cnf : CNF Nat) (cert : String) : Bool` | `Std/Tactic/BVDecide/Reflect.lean` | `parseLRATProof cert.toUTF8` then `check`; `verifyCert_correct : verifyCert cnf cert = true → cnf.Unsat` |
| `LRAT.trim` | `Lean/Meta/Tactic/BVDecide/LRAT/Trim.lean` | removes unused steps (untrusted tool step) |
| `Lean.Meta.nativeEqTrue` | `Lean/Meta/Native.lean` | compiles + evaluates a closed `Bool` term `e`; if `true`, adds an **auxiliary axiom** `_native.<tac>.ax_… : e = true` |

How `bv_decide` uses an external LRAT file (`Lean/Meta/Tactic/BVDecide/LRAT/Cert.lean`, `.../Prover/Bitblast.lean`,
`.../External.lean`): bitblast goal → AIG → `CNF Nat`; write `cnf.dimacs`; run cadical with
`<cnf> <proof> --lrat --binary=<b> --quiet --shrink=0 --unsat`; read the proof, optionally `LRAT.trim`, store it
as a `String` constant; build the term `verifyBVExpr expr cert`; call `nativeEqTrue` → axiom
`verifyBVExpr expr cert = true`; finish with `unsat_of_verifyBVExpr_eq_true`.
**`Lean.ofReduceBool` is deprecated in v4.33.1** (`Init/Core.lean`: "in-kernel native reduction is deprecated;
assert native evaluations with axioms instead") and is used neither by `bv_decide` nor by `native_decide`.

## 2. Our pipeline

1. `enc n k i1 canon types : CNF Nat` (Lean, `LeanLrat/Enc.lean`), DIMACS by `CNF.dimacs` (`lrat-tool dimacs`).
2. `bin/cadical -q --lrat=true --binary=false x.cnf x.lrat` (untrusted), optional `lrat-tool trim` (untrusted).
3. Result file `Results/*.lean` (generated by `tools/mkresult.sh`):
   `def cert : String := include_str "../cnf/x.lrat"` and
   `lower_bound_chain_snap n k iset _ _ (H_of_checkCert n k i1 canon (weakOrderTypes n) cert (by native_decide))`.
   `native_decide` evaluates `checkCert n k i1 canon types cert` (= `layoutOK … && verifyCert (enc …) cert`) with
   the compiler; the kernel checks everything else.

The DIMACS file is NOT trusted and NOT read by the check: `checkCert` recomputes `enc` inside the evaluated term.
A wrong export gives a failed check, never a false theorem. Same for cadical, trim, Python.

## 3. Trust base of a result theorem (e.g. `sort3_I1c_no_le7`)

`#print axioms` → `propext, Classical.choice, Quot.sound, <thm>._native.native_decide.ax_1_1`.
- Lean kernel (type checks the encoder soundness proof `LeanLrat.sound`, the Std checker proof
  `verifyCert_correct`, the `lean` agent's chain `lower_bound_chain_snap`).
- The aux axiom `checkCert … cert = true`: justified by the Lean compiler + runtime (LCNF/IR → C → clang, GMP),
  i.e. we trust that compiled `checkCert` computes the same `Bool` as its definition. This is the same trust as
  `bv_decide` / `native_decide`. An external checker (lean4checker / nanoda) can not re-check this axiom.
- Statement-level trust (what the theorem MEANS): the vendored semantics `vendor/SortProof/*` (byte copy of
  `agents/lean/frozen/v1`, see `tools/vendor_check.sh`): `XSnap`, `xrun`, x86 flag semantics.
- NOT trusted: cadical, `LRAT.trim`, `CNF.dimacs` file, `lrat-tool`, all scripts.

## 4. Encoder facts (v2, content encoding)
- Variables: `V` (op/dst/src/val/lt/gt/dv/sv/wr/nv/os/tc), dense numbering `layout` with a computed check
  `layoutOK` (`decode ∘ layout = id` on every variable of the CNF), so no injectivity proof is needed.
- Values = contents: `c < n` "holds x_c", `c = n` = T. Snapshot of output j = initial input `P_m` (`os j m`, m < n)
  or the new value of the first operand of step i (`os j (n+i)`). Correct by `snap_content` (last write).
- `canon = true` (`I1c`) adds the first-touch rule (sat's canon + pcanon). Proof: `LeanLrat.canonicalize`
  (class-preserving permutation of registers, `relaxed_snap_perm`).
- `norm = true` (`I1n`, with canon) adds the normal form `Normal` (nop = `mov P0,P0` only at the end; no
  cmovl/cmovg before the first cmp; every cmp read by a cmov before the next cmp/end; no self moves).
  Proof: `normalize`, `normal_rename_pad`, `sound_norm` (`LeanLrat/Normal.lean`).

## 5. Big proofs: cubes
`tools/cubes.py N K I TYPES JOBS VAR...` splits on variables (full binary tree), solves each cube
(`addUnits (enc …) cube`), trims, and writes one Lean file per cube (`leaf_…`: `verifyCert` by
`native_decide`) and `Main.lean`, which combines the leaves with the kernel lemma `unsat_split` and states
the x86 (`lower_bound_chain_snap`) and memory-model (`mm_lower_bound`, lean's L5) theorems.
Build: `lake build Results.<Tag>.Main` (each leaf is its own module, so memory stays per leaf).
- Soundness holds for ANY list `types` (CEGIS subsets OK); entries are taken `% n`.
