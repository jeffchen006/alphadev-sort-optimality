# Literature scan 2023-2026: shorter sort kernels, synthesis, min-max theory (2026-10-25)

Scope: work newer than (or missed by) our list: AlphaDev (Nature 2023), Ullrich & Hack (CGO 2025), Cruz-Filipe/Schneider-Kamp
optimality proofs, Codish et al. Search: web search, arXiv, OpenAlex citation lists of AlphaDev (176 citers) and Ullrich & Hack
(2 citers), GitHub.

Trust tags:
- **[READ]** = I read the full text (or the code) in this session.
- **[ABS]** = I read only the abstract / landing page / README.
- **[SNIP]** = I saw only a search snippet. Do not cite without a check.
- **[KNOWN]** = well-known paper; I did not open it in this session.

Headline: **I found no published sort5 kernel shorter than 42 instructions in AlphaDev's action space (mov/cmp/cmov, register
operands, 5 loads + 5 stores).** All shorter "sort3/sort4" results use other instructions (branches, sbb/adc + table
lookup, SIMD shuffle). The closest relevant work is Cruz-Filipe & Schneider-Kamp (LPAR 2024). They explain every AlphaDev saving
as "copy (mov) reuse". For n = 5 their method gets 43, not 42.

## 3. Min-max (lattice) theory relevant to comparison sharing

| # | Source | What it shows | Insight for us |
|---|---|---|---|
| 3.1 | **J. Harder, "An Answer to the Bose-Nelson Sorting Problem for 11 and 12 Channels", arXiv 2012.04400 (2020, v3 2022)** **[READ, sec. 1-3]** | s(11) = 35, s(12) = 39. Defines **partial sorting networks** on an input set X; subsumption (inclusion + permutation + negation). **Huffman bound (Thm 26):** `s(X) >= H_{1+max}{ s(X/i) : i prunable }`, where X/i = inputs where channel i holds the max, with the max path removed; H = Huffman's algorithm on the multiset. Generalises Van Voorhis `s(n) >= s(n-1) + ceil(log2 n)`. He notes that on **permutation** sets (our state sets) every channel that holds n in some input is prunable, so the bound applies directly. Isabelle-verified certificate checker. | A per-state admissible heuristic, not a global restriction bound. Our uniform "restrict to x_i = max" idea failed on data. But Huffman combines **different exact residual costs** s(X/i) (from our sort4 database) in a 1+max tree. To use it we must re-prove the path argument for cmov programs: a mov can copy the max (so paths form a DAG), and one flag feeds several cmovs. The δ per path node is probably ">= 1 cmp + 1 cmov". **Owner: theory/bounds.** It could lower the root slack (now 12-17), which SORT5_PROOF_EFFORT §4 says is the missing piece. |
| 3.2 | **Codish, Cruz-Filipe, Ehlers, Müller, Schneider-Kamp, "Sorting Networks: to the End and Back Again", JCSS 2016 / arXiv 1507.01428** **[READ, lemma statements via ar5iv]** | In a non-redundant network the **last layer has only (i,i+1) comparators** (Lemma 4). Penultimate-layer comparators join adjacent blocks, j - i <= 3 (Lemma 6, Cor. 2). Non-redundant last layers: F_{n+1} - 1. "Outside-in" search: fix the last layers first, then fill the middle with SAT. | For cmov programs the analog: the **last cmp** must split two adjacent ranks (only states differing by an adjacent transposition remain). Same for the last 2 blocks. This gives (a) a suffix filter for skeleton enumeration (D1), (b) "end constraints" for the proof search. It is the "back again" direction that sped their SAT runs by 10x. |

## 4. Transferable techniques from recent record results

| # | Technique (source) | How to transfer |
|---|---|---|
| 4.1 | **Flip graph + symmetry** (3.3). Walk only on correct objects of fixed length; try reductions at each step; restrict to a symmetry class. | Our 868,567 distinct 42s are a plateau. Define correctness-preserving flips: commute independent instructions; rename registers; swap cmp operands + flip all cc's of the block; replace a cmov source by a care-set-equal register (1.3 trick); move a mov to a different equal source. Try reduction = delete 1 instruction, or delete 2 + insert 1 with exact repair (small SAT over the window). Restrict to **reflection-symmetric** programs (reverse ranks, swap min/max = swap l/g cc's) to cut the space, like Moosbauer-Poole. Cheap check first: is the 868k set connected under these flips? If it splits into many components, a walk from each component is a new start. |
| 4.2 | **Outside-in search** (3.2) and **backward curricula** (2.5). | Enumerate the last 2-3 cmp blocks (they are very restricted: adjacent ranks), then solve the prefix with SAT. A meet-in-the-middle between forward states and backward "pre-sorted" states may cut the 1e15 estimate. |
| 4.3 | **LLM evolution harness choice** (AlphaEvolve 1.5; Gupta et al., "Automated Discovery Has No Universally Superior Harness", arXiv 2607.18235, Jul 2026 **[ABS]**: 30 harnesses x 12 tasks, 3.1M rollouts; no harness is best; OpenEvolve variants often lose to simpler ones; early progress predicts final; adaptive start-many-prune-weak wins). FunSearch: Romera-Paredes et al., Nature 625 (2024), doi 10.1038/s41586-023-06924-6 **[KNOWN; metadata checked]**: evolve a short *program that builds* the object, not the object. | For D4: (a) run 3-5 harness variants, prune after a short budget; (b) let the LLM write **skeleton generators** / priority functions (FunSearch style) that the exact router (D1) completes, not raw asm. |
| 4.4 | **0/1 reduction for reuse checks** (2.1, Lemma 1) and 0-1 test states (2.5). | When the reuse source is the partner of a min/max, a 0/1 counterexample suffices -> fast SAT filter before full permutation checks (120 perms). Not valid for general sources. |
| 4.5 | **Verified certificates** (Harder: Isabelle checker; Codish et al.: Coq checker; flip graphs: none). | Matches our Lean/Rocq path; Harder's DP certificate (derivation of each s(X) bound) is a format to copy for an h-based proof. |

## 5. Top 5 actionable insights for our team

1. **Close the "network + copy reuse" family exactly (cheap, 1-2 h).** Cruz-Filipe & Schneider-Kamp (LPAR 2024) show that all AlphaDev savings are skipped movs. A 41 with 9 cmp and 18 cmov needs **5 skipped movs** (4 movs left). Enumerate all non-isomorphic 9-comparator 5-networks × all topological orders × top and bottom (min and max side) reuse, with reuse sources = any live register incl. **load registers**. Check each candidate with SMT (or the 0/1 SAT shortcut when it is valid). If the maximum is 4 everywhere, write it as a negative result: "no network-derived 41". If it is 5, we have a 41.
2. **Get a cmov saving, not only a mov saving: care-set sources and shared terms.** The libc++ `__partially_sorted_swap` (1.3) uses `x = r ? x : y`. The cmov reads an **original** register that equals the needed min only where the cmov fires. A cmov can be removed only if some register already holds the correct value in **both** flag cases, i.e. a lattice term that is computed twice (a common subexpression) or a precondition that makes it equal. D2 (lattice DAG) should count cost as `cmp + Σ(cmov) + copies`, with a "free" output when a node equals an existing register on its care set.
3. **c = 7/8 needs non-lattice comparands: use the Ford-Johnson shapes.** No branchless 7-comparison sort5 is published. Our proof says c <= 8 needs a non-lattice operand. Ford-Johnson gives the natural ones: partner-of-winner `sel(f; min(a,b), min(c,d))` and the binary-insertion pivot `sel(f; a, d)`. One flag drives a **pair swap** (4 cmovs). Budget: for k = 31 with c = 7, W <= 24, so each of the 7 flags must drive more than 3 writes on average (counting movs). Seed D3 with these skeletons only; let the exact router place cmov/mov.
4. **Huffman bound (Harder 2020) as an admissible h for the proof search.** For a state set X: `h(X) >= H_{1+max}{ h_or_exact(X/i) }`, over every input i that is the max in some permutation of X. The inner values come from the exact sort4 table. First prove the cmov version of the "max-path" lemma (copies make the path a DAG; flags are shared). A per-node δ >= 2 (cmp + cmov) would double the Van Voorhis increment. This is the "admissible h with small slack" that SORT5_PROOF_EFFORT §4 needs.
5. **Flip-graph walk on the 868k plateau with symmetry + outside-in filters.** Test connectivity of the 42-set under correctness-preserving flips (list in 4.1). Then run reduction attempts (delete 1, or delete 2 + insert 1 with exact window repair) from every component. Restrict one run to reflection-symmetric programs. Prune skeletons with the end-of-network rule (last cmp splits adjacent ranks; penultimate blocks are limited, 3.2).

- No lower bound on min/max-gate count with fan-out for small n; no cmov-program lower bound beyond Ullrich & Hack's n = 4.
- No branchless Ford-Johnson sort5.
