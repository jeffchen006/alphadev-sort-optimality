# Round 8 method

Purpose: replace three consecutive instructions with two legal instructions at k=31. Sources are the same frozen 144 k=32 variants, but this relation differs from the earlier two-position near-miss repair.

The original output-2 snapshot defines the median. Concrete execution confirms that each source has exactly one write snapshot whose full value column equals the median on all 541 weak orders. The median accumulator chain follows the previous destination definition through each CMOV and follows the source definition through each MOV. This is one backward path, not the complete dependency tree. Source branches of CMOVs and comparison dependencies are not on this path unless reached through those rules. The audit also retains the broader value-dependency slice.

A width-three window is selected if it contains a chain instruction. The 144 variants give 1,720 selected windows. Queries near the median producer run first. All indices are zero-based core indices. Sources, hashes, chain instructions, and queue order are in manifest.json, median_audit.json, and queue.json.

For each selected window [s,s+3), replace its instructions with two arbitrary instructions. The two instructions can choose any of the six opcodes and any register operands, including equal operands. Outside the window, all CMOV predicates are free to choose l/le/g/ge. Their operands stay fixed. Outside MOV and CMP instructions stay fixed. Two fresh registers supplement every source register. Outputs can select snapshots again. No value palette or comparison skeleton constrains the free instructions. Because outside predicates are free, this is wider than an ordinary fixed-suffix window replacement.

The encoder uses three-bit concrete ranks. Initial scratch values are 7 and initial flags are equal. These are necessary conditions for strict correctness. Each query starts with twelve sampled strict orders and up to three failing cases for each nearest output of a provisional deletion. Common output selectors apply across all cases. Each relaxed proposal is evaluated on all 541 weak orders. Counterexamples extend the formula. SAT assignments are checked against every emitted clause before decoding. Any candidate must pass both strict reference judges.

Kissat gets a shared 1,200-second wall budget per query, including formula generation and counterexample refinements. Jobs run sequentially, at nice level 19, pinned to one inherited CPU. Each process has a 2,800 MiB address-space limit. The solver wrapper also checks combined encoder and solver resident memory against 2,800,000 KiB. A wall or memory limit is UNKNOWN. Unstarted queries are not exclusions. Exit code 20 and the UNSAT output line are both required for each bounded UNSAT result. No global instruction lower bound follows.

The positive control duplicates the last CMP of source 0, giving 33 instructions. It replaces the resulting three-instruction window by two free instructions, with the same outside predicate freedom and two extra registers. The returned k=32 candidate must pass both strict judges. This tests the exercised relation but does not prove its encoding.

Assumption tags: [G1,G2,G3,A2,A11]. This tests local repair A11 and extends the scratch-register alphabet A2. Source and window selection remain finite. No result by itself establishes global optimality.

After 124 direct queries, a worker-side equivalence check was added. A query can inherit a completed direct UNSAT only when its full finite repair relation matches under separate input-register and scratch-register bijections. Input renaming preserves sorting because the required outputs are the sorted ranks of the same five inputs. Scratch renaming preserves the relaxed initial state because every scratch starts at 7. The canonical relation retains every MOV/CMP opcode, every outside operand, every free-slot position, the full register count, and the fact that every outside CMOV can choose any condition. No comparison reversal is used. A separate final audit composes the recorded register maps and directly checks every constrained instruction. An inherited result is recorded as UNSAT_EQUIVALENT, not as a new solver UNSAT. All representatives must have a direct solver UNSAT.
