C1-to-C2 column bound gap: C1's proposed lemma replaces a strictly correct program by a program with defined reads and core length at most the original length. The proof accounts for a live garbage-class root. It does not bound the number of non-lattice written register versions after replacement. A non-lattice version is a value column that cannot be expressed by min and max of the inputs. Copies count as separate written versions. Specializing garbage can change intermediate values, and later class splits can add copies. Therefore the lemma does not show that every scoped k<=31 program with a garbage comparison has an equivalent k<=31 program with at most two non-lattice written versions. That bound is required by both C2 variants. V1 also requires lattice comparison operands; V2 allows the two exceptional versions as comparison operands. To close this gap, prove the stated length-and-column bound for every garbage-comparison program in the declared Direction A scope, with all copies counted and the appropriate comparison hypotheses, or complete a certified exhaustive search that covers the missing programs or the larger normalization image. Judge acceptance of garbage removal alone does not close this gap.

Mixed three-column reduction gap: Let q count written versions with initial-scratch entries and let r count originally full non-lattice written versions. Assume every comparison reads defined values and every other written version is lattice. The established q-to-q-1 lemma requires r=0. It therefore maps q<=3 partial versions into at most two full non-lattice versions. For r>0, the general same-length garbage-removal construction preserves original full versions but guarantees only at most q+r exceptional versions. The first partial replacement can copy an earlier non-lattice value, so the proof does not guarantee a one-version saving. The unproved boundary cases are (q,r)=(1,2) and (2,1), and the broader three-version statement also includes (0,3), where there is no partial version to eliminate. To close this gap, prove that every scoped k<=31 program in these cases has an equivalent k<=31 fully defined program with at most two non-lattice written versions, including copies, and comparison operands allowed by V2; alternatively, decide the missing three-version cases directly with checked DRAT/LRAT certificates. An explicit scope restriction would remove these cases from the claim but would not decide them.
